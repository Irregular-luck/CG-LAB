# Computer Graphics & Image Processing Lab - Programs

One folder per question (Q01 ... Q37). Each folder has
- `a_*.py`  : the computer graphics program (part a)
- `b_*.py`  : the image processing program (part b)
- `input.jpg` : a sample image used by part b (replace it with any image you like, keep the name)

## Setup (once)
    pip install numpy matplotlib pillow

## Run
    cd Q01_sun_rising
    python a_sun_rising.py
    python b_hist_eq.py

Animations open in a Matplotlib window and loop until you close it.
